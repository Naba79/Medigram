🏥 Medigram - Flutter UI & Provider Practice App

A clean and modern frontend mobile application built with Flutter and Provider, inspired by a Dribbble UI design. This project was developed as a practice exercise to master state management, widget composition, and smooth screen navigation.

✨ Features

Interactive Dashboard: A sleek home screen featuring options like Book Doctor, Buy Medicine, Ambulance, and Blood Bank.

Specialty Selection: Browse through various medical fields such as Cardiologist, Dermatologist, Dentist, Neurologist, and Urologist.

Dynamic Doctor Lists: View tailored lists of professional doctors with their hospital affiliations and ratings based on the selected specialty.

State Management: Implemented using Provider to handle basic UI states and screen transitions smoothly.

🛠️ Tech Stack

Framework: Flutter & Dart

State Management: Provider

Design Inspiration: Dribbble

🚀 Getting Started

To run this project locally on your machine:

Clone the repository:

git clone https://github.com/Naba79/Medigram-App.git


Install dependencies:

flutter pub get


Run the application:

flutter run
